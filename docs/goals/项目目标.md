# WeaveNet 织网穿透 项目目标文档

> 项目：准商业级 FRP 全套程序（服务端、客户端、管理端、官网）
> 品牌：WeaveNet・织网穿透
> 对标：https://www.chmlfrp.net/
> 文档：CQFISH&喵酱出品
> 日期：2026-08-15

## 1. 项目定位

本项目定位为**准商业核心版内网穿透服务平台**，不追求一步到位的完整商业化，而是先打牢核心能力，为后续平滑升级到完整商业化模式预留架构空间。

项目包含四个子系统：

| 子系统 | 说明 |
| --- | --- |
| FRP 服务端 | Go 内核，基于 fatedier/frp 二次开发，提供穿透能力 |
| 桌面客户端 | Electron 桌面程序，托管 frpc 子进程，免配置即用 |
| 管理面板 | FastAPI 后端 + Vue3 前端，承载用户与管理员全部业务 |
| 官网 | FastAPI + Jinja2 服务端渲染，11 个页面 |

目标规模：

| 指标 | 目标 |
| --- | --- |
| 注册用户 | 1 万以内 |
| 在线隧道 | 500 以内 |
| 部署形态 | 单机 Docker Compose 部署，保留中间件支撑业务架构 |
| 内存占用 | 整体 200MB 以内 |

## 2. 产品目标

### 2.1 隧道全家桶

服务端与客户端全量支持主流隧道类型：TCP / UDP / HTTP / HTTPS / STCP 安全隧道 / XTCP 点对点 / KCP 加速 / 负载均衡 / 免费三级域名。

### 2.2 免费三级域名

用户可在线申请免费三级域名（开发期使用 weave.test 占位域名，上线前替换为正式域名并配置泛解析），面板校验占用后生成域名并按域名路由。

### 2.3 每日签到积分

用户每日可签到获取积分，连续签到有额外奖励，积分可用于兑换会员时长，形成轻量化的用户激励与留存机制。

### 2.4 公告与工单

站内公告用于官方消息发布（发布时填写发布人/部门名称）；工单用于用户问题反馈，支持创建、回复、关闭全流程。

### 2.5 桌面客户端免配置

Electron 桌面客户端登录面板账号后自动拉取名下隧道，一键启动/停止，实时展示状态与流量，由程序自动生成 frpc.toml 配置并托管 frpc 子进程生命周期，用户无需手写任何配置文件。

## 3. 商业目标

### 3.1 四档套餐

| 档位 | 限速 | 隧道数 | 免费域名 | 流量 |
| --- | --- | --- | --- | --- |
| 免费版 | 8Mbps | 3 条 | 1 条 | 不限 |
| 普通会员 | 16Mbps | 6 条 | 4 条 | 不限 |
| 高级会员 | 24Mbps | 10 条 | 8 条 | 不限 |
| 超级会员 | 32Mbps | 14 条 | 16 条 | 不限 |

会员到期后自动降级回免费版（每小时检查一次）。

### 3.2 虚拟积分与签到体系

- 每日签到得 10 积分，连续签到 7 天额外 +30 积分
- 积分兑换：300 积分 = 1 个月普通会员
- 管理员可在后台调整签到积分规则
- 积分变动全部记入积分流水，可追溯

### 3.3 支付策略

本阶段不接入真实支付，采用虚拟积分 + 签到体系完成商业化闭环；架构上预留套餐、订单、积分与额度管理等能力，后续可平滑升级到真实支付，无需重构。

## 4. 技术目标

### 4.1 技术栈

| 组件 | 技术选型 |
| --- | --- |
| 服务端/客户端内核 | Go，基于 fatedier/frp 二次开发（Apache 2.0 可商用） |
| 面板后端 | Python 3.12 + FastAPI，uvicorn 单进程 |
| 数据库 | SQLite（WAL 模式 + busy_timeout） |
| 缓存/会话 | 轻量 Redis（单实例） |
| 异步任务 | asyncio 后台任务（不引入 Celery/消息队列） |
| 面板前端 | Vue3 + Naive UI，构建为静态文件 |
| 官网 | FastAPI + Jinja2 服务端渲染 |
| 桌面客户端 | Electron（Windows 10/11 x86_64），托管 frpc 子进程 |
| 应急服务 | 独立轻量进程（标准库实现，零依赖） |
| 部署 | Docker Compose（4 容器） |

### 4.2 内核二开目标

frps 二次开发需实现：控制通道 API（节点注册与心跳上报）、隧道配置热拉取（每 10s 从面板拉取本节点隧道与用户限速配置，热更新无需重启）、客户端鉴权对接（校验面板签发的用户 Token）、按套餐动态限速、状态上报（每 30s 上报在线隧道、连接数、流量增量）、远程端口分配校验。frpc 侧通过 Token 鉴权连接 frps，配置由客户端自动生成。

### 4.3 容器编排

Docker Compose 编排 4 个容器：

| 容器 | 职责 |
| --- | --- |
| weave-panel | FastAPI 面板 + 官网 + 静态前端，挂载 sqlite 数据卷 |
| weave-redis | redis:7-alpine |
| weave-frps | Go 穿透服务端，暴露 7000（控制）/80/443（隧道） |
| weave-emergency | 应急服务，端口 9001（仅内网/VPN 访问） |

## 5. 非功能目标

### 5.1 安全目标

- 密码使用 bcrypt 加密（不少于 10 轮）
- 会话采用 64 位随机 Token，30 天过期；用户/管理员通过请求头 Bearer 鉴权，角色中间件校验
- frps 节点使用独立 Agent Token，仅允许访问 /api/agent/* 接口
- 隧道越权防护：ORM 层强制 user_id 过滤，杜绝横向越权
- 登录、注册、签到接口限流（IP + 账号双维度）
- 邮箱验证码防暴力（次数限制），验证码 5 分钟有效
- 远程端口池管理，禁止系统保留端口
- 应急 API 使用强随机预共享密钥（不少于 32 位），连续失败 5 次锁定 10 分钟

### 5.2 可靠性目标

- 应急 API 逃生通道：独立进程/容器，与面板完全解耦，面板、数据库、Redis 全部故障时仍可响应，支持健康检查、状态查询、日志拉取、数据读取、服务启停与服务器重启
- SMTP 发送失败进入队列重试 3 次
- SQLite 锁冲突通过 WAL + busy_timeout 缓解，写操作自动重试
- 客户端网络中断时 Electron 指数退避重连
- frps 掉线标记节点离线，不阻塞其他功能；心跳超过 60s 无响应标记节点离线

### 5.3 性能目标

- 整体内存占用控制在 200MB 以内
- 支撑 500 条在线隧道场景下，面板正常响应、Redis 实时状态正常刷新

## 6. 里程碑规划

### M1 内核与面板基础

范围：用户体系、隧道管理、节点管理、认证体系。

可验证交付物：
- 用户注册、登录、邮箱验证、找回密码、登出全流程可用
- 隧道 CRUD 与启停功能可用
- 节点增删改与状态展示可用
- 用户/管理员/Agent 三级认证体系落地
- frps 二开完成节点注册、心跳上报、隧道配置拉取、客户端 Token 鉴权
- SQLite（WAL）与 Redis 基础接入完成

### M2 套餐积分体系

范围：套餐档位、每日签到、积分兑换、免费域名。

可验证交付物：
- 四档套餐（免费/普通/高级/超级）配置与额度校验生效
- 套餐限速联动 frps 按用户 Token 动态限速
- 每日签到、连续签到奖励、积分流水完整可用
- 积分兑换会员时长功能可用，会员到期自动降级免费版
- 免费域名申请/释放全流程可用，frps 按域名路由

### M3 管理后台与官网

范围：11 页官网、管理后台全功能、公告工单、统计。

可验证交付物：
- 官网 11 页全部上线：首页、下载中心、文档、公告、定价、关于我们、服务条款、隐私政策、更新日志、服务状态、帮助中心
- 管理后台全功能可用：用户管理、节点管理、全局隧道管理、套餐配置、公告发布（含发布人）、系统配置、操作日志、统计看板
- 公告与工单模块全流程可用
- 流量统计按日聚合与在线概览展示可用

### M4 客户端与部署交付

范围：Electron 客户端、应急服务、Docker Compose 全套部署、端到端验证。

可验证交付物：
- Electron 桌面客户端（Windows 10/11）完成登录、隧道拉取、一键启停、状态与流量展示
- 应急服务独立进程上线，应急 API 接口全部可用
- Docker Compose 4 容器一键编排部署完成
- 端到端流程验证通过：注册、建隧道、客户端连接、公网访问

## 8. 交付范围说明

- 开放 API：暂不对外开放，内部接口架构预留，稳定后再评估对外开放
- 界面语言：简体中文，暂不做 i18n
- 客户端平台：首发仅 Windows 10/11（x86_64），其他平台后续版本扩展
- 免费域名：开发期使用占位域名（weave.test），上线前替换为正式域名并配置泛解析
- HTTPS 证书：手动上传证书配置，不支持自动签发
