# WeaveNet 织网穿透 开发文档

> 项目：准商业级 FRP 全套程序（服务端、客户端、管理端、官网）
> 品牌：WeaveNet・织网穿透
> 文档：CQFISH&喵酱出品
> 日期：2026-08-15

本文档面向开发者，依据《2026-08-15-weavenet-design.md》设计文档与《FRP-需求收集.md》需求文档编写，说明 WeaveNet 各子系统的技术实现、代码结构、模块划分与开发规范。

## 1. 项目概述

WeaveNet 是一套准商业级 FRP 内网穿透平台，包含四个子系统：

| 子系统 | 技术栈 | 说明 |
| --- | --- | --- |
| 面板后端 | Python 3.12 + FastAPI | 用户侧 / 管理后台 / 内核联动 / 客户端 API，官网渲染 |
| 面板前端 | Vue3 + Vite + Naive UI | 用户面板与管理后台 SPA |
| 穿透服务端 | Go 1.25 | frps 二开内核，Agent 联动面板 |
| 桌面客户端 | Electron + frpc | Windows/macOS/Linux 隧道管理 |
| 应急服务 | Python 标准库（零依赖） | 独立逃生通道，端口 9001 |
| 官网 | FastAPI + Jinja2 | 产品介绍、下载、文档、FAQ 等 11 页 |

采用单仓库 Monorepo 结构，根目录 `e:\FRPserver`，子系统目录为 `panel`、`server`、`client`、`emergency`、`deploy`、`docs`。

## 2. 技术栈与关键依赖

- 后端：FastAPI、SQLAlchemy 2.0、SQLite（WAL）、Redis、bcrypt、Jinja2、httpx
- 前端：Vue3、Vite、Vue Router、Pinia、Naive UI、axios
- 服务端：Go 1.25 标准库 + gorilla/websocket（自定义 JSON-line 帧协议）
- 桌面端：Electron + Node.js，frpc 子进程托管
- 部署：Docker Compose（4 容器：panel / redis / frps / emergency）

## 4. 面板后端

### 4.1 分层设计

后端采用标准分层：`api（路由层）→ services（业务层）→ models（数据层）`，公共能力集中在 `core`。

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| core/config.py | 配置项 | 从环境变量读取，含 admin 账号、SMTP、Redis、限流参数 |
| core/database.py | 数据库 | SQLAlchemy 引擎、SessionLocal、get_db 依赖 |
| core/security.py | 安全 | bcrypt 密码哈希、会话 Token、Agent Token、验证码、应急密钥生成 |
| core/errors.py | 错误 | BizError 异常体系与统一响应 `{code, message, data}` |
| core/deps.py | 依赖 | get_current_user / get_current_admin / get_agent_node / 限流工厂 |
| core/redis_client.py | Redis | 会话、隧道实时状态、流量计数、限流，支持无 Redis 内存降级 |

### 4.2 数据模型

共 15 张表：User、Plan、Node、Tunnel、Domain、SigninLog、PointsLog、Ticket、Announcement、TrafficStat、SystemConfig、Session、EmailCode、OperationLog、UserPlanLog。

关键设计：隧道表含 type（tcp/udp/http/https/stcp/xtcp/kcp/loadbalance）、subdomain、custom_domain、secret_key、load_balancers；节点表含 agent_token（`agent_` 前缀，48 位随机）；会话表双写 Redis 与 SQLite。

### 4.3 认证与权限

- 用户与管理员使用 64 位随机会话 Token，30 天过期，`Authorization: Bearer` 携带
- 角色隔离：get_current_admin 校验管理员；get_agent_node 校验 `agent_` 前缀的节点 Token
- 邮箱验证码用于注册激活与找回密码，5 分钟有效，防暴力次数限制
- 注册 / 登录 / 签到按 IP + 账号维度令牌桶限流（HTTP 429）
- 隧道数据在 ORM 层强制 user_id 过滤，防止越权

### 4.4 业务错误码

成功统一返回 `{code:0, message:"ok", data}`；失败返回 HTTP 状态码 + `business_code`，业务码段 1001-9001，详见 API 文档第 1.4 节。

### 4.5 后台任务

`tasks/scheduler.py` 三个协程循环：会员套餐过期检查（每小时）、流量按日聚合（每 5 分钟）、节点心跳扫描与离线标记（每 60 秒）。

### 4.6 内核联动

`api/agent.py` 面向 frps：注册、心跳、隧道拉取。frps 每 10s 拉取隧道与限速配置，每 30s 心跳上报隧道状态与流量增量；面板将实时状态写入 Redis 并持久化当日流量。

## 5. 面板前端

### 5.1 技术方案

Vue3 + Vite 构建，产物输出到 `web/dist`，由后端以 `/panel` 静态挂载；开发时 Vite 代理 `/api` 到后端。

### 5.2 页面清单

用户端 12 页：登录、注册、忘记密码、工作台、隧道管理、域名管理、流量统计、积分商城、套餐、个人资料、工单、公告。

管理端 10 页：管理登录、管理布局、统计看板、用户管理、节点管理、隧道管理、套餐管理、公告管理、系统配置、操作日志。

### 5.3 设计规范

玻璃拟态风格：浅色半透明卡片、青蓝渐变主色（#0ea5e9 至 #06b6d4）、暖橙点缀（#f59e0b 至 #f97316）、无阴影无浮动、图标使用 SVG（SvgIcon 组件）、状态用 StatusBadge 组件。

## 6. Go 穿透服务端

### 6.1 模块划分

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| internal/config | config.go / util.go | 简易 key=value 配置解析 |
| internal/agent | agent.go | 面板联动：注册、每 30s 心跳、每 10s 拉取隧道配置 |
| internal/server | server.go | TCP / UDP / HTTP vhost 转发，自定义 JSON-line 帧协议（auth/proxy/data） |
| internal/server/limiter | limiter.go | 令牌桶限速，按用户维度限流 |

### 6.2 与面板的协作

frps 启动携带 Agent Token 调用 `/api/agent/register`；每 10s 拉取本节点隧道、用户限速与域名路由表（热更新无需重启）；每 30s 上报隧道在线状态、连接数、流量增量。

## 7. Electron 桌面客户端

- 主进程 main.js 管理窗口与 frpc 子进程生命周期
- 预加载脚本 preload.js 暴露安全 API
- 渲染进程 renderer 提供登录、隧道列表、一键启停、状态与流量展示
- 内置 `bin/frpc.exe`，由面板 `/api/client/*` 接口驱动生成 frpc.toml

## 8. 应急服务

`emergency/emergency.py` 纯 Python 标准库实现，零第三方依赖，独立于面板进程，端口 9001。提供 /health、/status、/logs、/data、/restart、/reboot、/exec 接口，HMAC 预共享密钥鉴权，连续 5 次鉴权失败锁定 10 分钟。

## 9. 本地开发与构建

```powershell
# 面板后端
cd e:\FRPserver\panel
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8080

# 面板前端构建
cd e:\FRPserver\panel\web
npm install
npm run build

# Go 服务端
cd e:\FRPserver\server
go build -o bin\frps.exe .\cmd\frps
go build -o bin\frpc.exe .\cmd\frpc

# 应急服务
python emergency.py --config emergency.conf

# 测试
cd e:\FRPserver\panel
.\.venv\Scripts\python -m pytest tests/ -v
.\.venv\Scripts\python tests\smoke_test.py
```

## 10. 编码规范

- 模块化、组件化开发，职责单一，禁止循环依赖
- 统一响应格式与业务错误码，禁止裸抛 HTTPException
- 注释使用中文纯文字，不使用长破折线与 Emoji
- 关键参数（端口、业务码、套餐数值、时间阈值）以设计文档为准，一处修改需同步其余文档与代码
- 所有文档与代码声明出品方 CQFISH&喵酱出品
