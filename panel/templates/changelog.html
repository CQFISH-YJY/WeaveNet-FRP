最新版本

v0.1.0 · 初始版本发布

发布于 2026-08-01

WeaveNet 织网穿透首个正式版本上线，这是一个从零打造的准商业级 FRP 内网穿透平台，核心能力如下：

账号体系

  • 注册 / 登录 / 退出，支持邮箱验证与密码找回。
  • 密码 bcrypt 加密存储，64 位随机 Token 会话认证。
  • 个人资料与安全设置管理。

隧道管理

  • 支持 TCP、UDP、HTTP、HTTPS、STCP、XTCP、KCP 全类型隧道。
  • 隧道在线状态实时展示，一键启停与删除。
  • 多节点选择与负载均衡支持。

域名+端口直连

  • 创建隧道自动分配公网端口，通过「节点域名+端口」访问，无需申请域名。
  • 公网地址在面板隧道管理中实时展示。

桌面客户端

  • Windows 10 / 11 x64 免配置客户端。
  • 登录自动同步隧道配置，托盘实时流量展示。

积分与会员

  • 每日签到积分体系，300 积分兑换 1 个月普通会员。
  • 免费版 / 普通 / 高级 / 超级四档会员，全部不限流量。

平台能力

  • 工单系统：问题提交、处理进度跟踪。
  • 公告系统：平台动态与维护通知。
  • 实时流量统计与节点心跳监控。

感谢每一位参与内测的用户，期待与你共同织出更广阔的网。

后续规划

  • macOS / Linux 桌面客户端。
  • 更多区域节点与更高带宽档位。
  • 团队协作与多成员管理。

以上规划仅供参考，具体以实际发布为准。
